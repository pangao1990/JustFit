# 《装满这一箱》微信小游戏运营素材

本目录中的成品素材用于微信小游戏后台单独上传，不属于小游戏代码包。`project.config.json` 已将整个 `doc` 文件夹加入上传忽略项。

## 成品清单

- `01-general-cover-650x250.jpg`：通用素材封面，650×250，JPG，不超过 80KB，无文字、无 Logo。
- `02-promo-vertical-01-720x1280.jpg` 至 `03`：竖版详细推广图，720×1280，单张不超过 200KB。
- `03-promo-horizontal-01-1280x720.jpg` 至 `03`：横版详细推广图，1280×720，单张不超过 200KB。
- `04-promo-copy.txt`：后台推广文案、视频文案和小程序简介。
- `05-promo-video-cover-1280x720.jpg`：推广视频封面，16:9，单张不超过 200KB。
- `05-promo-video-1280x720.mp4`：12 秒横版推广视频，H.264 + AAC。
- `06-share-image-500x400.jpg`：分享图片，500×400。

## 已核对的后台规范

- 通用素材封面：JPG/JPEG，650×250，不超过 80KB；不放游戏图标、游戏名、标题或 Slogan。
- 竖版推广图：JPG/JPEG/PNG，720×1280，上传 3 张，单张不超过 200KB。
- 横版推广图：JPG/JPEG/PNG，1280×720，上传 3 张，单张不超过 200KB。
- 推广文案：最多 8 个字。
- 推广视频：10–20 秒，分辨率不低于 1280×720，16:9，MP4，H.264，AAC，小于 100MB；封面建议 1280×720、16:9、单张不超过 200KB。
- 分享图片：JPG/JPEG/PNG，500×400，单张不超过 2MB。

`source/` 保存实机截图和可继续修改的排版源稿，同样不会被上传到小游戏代码包。
