## 推荐上传组合

### 场景（至少3张）

1. `01-主界面-首页.png`
2. `07-系统-奇趣藏馆.png`
3. `09-场景-玩法说明.png`

### 玩法（至少3张）

1. `02-玩法-第15关三目标.png`
2. `03-玩法-第18关炸弹.png`
3. `04-玩法-第22关限步目标.png`

### 系统功能（每个至少1张）

- 货币系统：`10-系统-藏品换金币.png`。
- 商城系统：`05-系统-补给商店.png`。
- 道具系统：`06-系统-道具购买.png`。
- 排行榜系统（若填写）：`11-系统-好友榜藏品.png`。

以上推荐组合中的每张图片只上传一次，不跨模块复用。`备用截图/08-系统-好友榜金币.png`不要在本次备案中上传。

## 成品检查方法

```bash
sips -g pixelWidth -g pixelHeight doc/备案材料/待上传截图/*.png
ls -lh doc/备案材料/待上传截图/*.png
```

检查结果应满足：每张均为 `514×1146`，且文件大小介于 60KB 和 5MB 之间。
